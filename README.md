# 植物病害识别项目：当前进度与详细实施方案

## 1. 项目基本信息

*   **目标**：构建基于 MobileNetV3-small 的植物病害识别系统，实现 Android 端高效部署。
*   **核心框架**：PyTorch (训练), TensorFlow Lite (部署)。
*   **当前阶段**：模型训练已完成，进入深入实验分析与 App 开发阶段。

## 2. 数据集现状

*   **涵盖作物**：辣椒 (Pepper)、马铃薯 (Potato)、番茄 (Tomato)。
*   **类别总数**：15 类（含健康及多种常见病害）。
*   **样本规模**：共 20,638 张图像。
*   **样本分布**：
    *   **最大类**：Tomato__Tomato_YellowLeaf__Curl_Virus (3208张)。
    *   **最小类**：Potato___healthy (152张)。
    *   **特征**：存在明显的长尾分布（类别间差异达 21 倍），已确定需使用类别权重（Class Weights）优化。
*   **数据集划分**：训练集:验证集:测试集 = 7:1.5:1.5。

## 3. 模型训练状态

*   **网络架构**：MobileNetV3-small (迁移学习)。
*   **训练策略**：
    *   **优化器**：Adam。
    *   **损失函数**：CrossEntropyLoss (带类别权重)。
    *   **数据增强**：RandomResizedCrop, RandomHorizontalFlip, RandomRotation 等。
*   **训练结果**：
    *   **Epochs**：15。
    *   **收敛性**：首轮验证集准确率即达 92.42%，第 13 轮达到峰值。
    *   **最佳验证准确率**：**99.35%**。
    *   **最优权重文件**：已保存最佳模型权重（待转换为 TFLite）。

## 4. 深入实验方案

### 4.1 消融实验 (Ablation Study)

*   **任务**：验证高准确率的来源。
*   **对比项**：
    1.  **Baseline**：无数据增强 + 无类别权重。
    2.  **+Augmentation**：添加数据增强后的提升。
    3.  **+ClassWeights**：针对少数类（如 Potato_healthy）的召回率提升。
    4.  **Transfer Learning**：对比从零训练与迁移学习的收敛速度。

### 4.2 鲁棒性测试 (Robustness Testing)

*   **任务**：模拟实际复杂环境下的识别稳定性。
*   **重点干扰**：
    1.  **高斯噪声**：模拟拍摄时的噪点。
    2.  **高斯模糊**：模拟对焦不准。
*   **产出指标**：干扰强度-准确率退化曲线图。

### 4.3 模型可解释性

*   **技术**：Grad-CAM 可视化。
*   **目标**：展示模型在番茄/马铃薯叶片上对“病斑”区域的响应，证明决策的科学性。

## 5. 模型部署与转换

*   **转换路径**：`.pth` -> `.onnx` -> `.tflite`。
*   **量化对比实验**：
    *   **FP32**：原始精度参考。
    *   **FP16**：平衡体积与精度。
    *   **INT8**：极致推理速度（需量化校准）。
*   **产出指标**：模型文件体积（MB）、Params (参数量)、FLOPs (计算量)。

## 6. Android App 开发方案

*   **核心功能**：
    1.  **识别模式**：点击拍照识别（离线静态识别）。
    2.  **结果展示**：类别名称、置信度、对应的病害防治建议。
*   **集成方式**：通过 `TFLiteClassifier` 模块封装模型推理代码，集成入 Android Studio 项目。

*   **测试设备**：确定的 Android 手机型号（待补充）。

    *   **资源占用**：CPU 占用率、内存占用峰值。
    *   **性能对比**：不同量化方案在真实设备上的运行差异。
